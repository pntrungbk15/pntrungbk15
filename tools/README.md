# Profile assets

The images in `assets/` are generated by the scripts in this folder.

- `svg_assets.py` writes the animated hero, divider and footer SVGs. Text is converted to outlines
  (`textpath.py`, HarfBuzz shaping), so the SVGs need no web fonts; motion is CSS and stops under
  `prefers-reduced-motion`.
- `raster_assets.py` lays out the project cards and the stack panel in HTML and renders them with Chromium
  (Playwright) into WebP and PNG, in dark and light, wide and narrow variants.
  Slugs after the output folder (`raster_assets.py ../assets docflow-idp`) render only those cards.

## Rebuild

```bash
uv venv .venv && uv pip install uharfbuzz fonttools pillow playwright && .venv/bin/playwright install chromium
mkdir -p tools/fonts tools/shots
curl -L -o /tmp/inter.zip https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip
curl -L -o /tmp/jbm.zip https://github.com/JetBrains/JetBrainsMono/releases/download/v2.304/JetBrainsMono-2.304.zip
python -m zipfile -e /tmp/inter.zip tools/fonts/inter && python -m zipfile -e /tmp/jbm.zip tools/fonts/jbm
# screenshots, from the public showcase repositories
R=https://raw.githubusercontent.com/pntrungbk15
curl -o tools/shots/veyra-design-dark.png  $R/veyra-showcase/main/docs/images/design-dark.png
```
